# zaiqingchun silver supermarket (Streamlit)

Static site (HTML/CSS/JS) hosted via a Streamlit custom-component frontend,
so it is reachable on Streamlit Community Cloud.

## Deploy to Streamlit Community Cloud
1. Push this repo to GitHub (account abaic2).
2. Open https://share.streamlit.io and authorize with GitHub.
3. New app -> pick this repo -> Main file path: app.py -> Deploy.
4. After deploy you get a public URL; generate a QR code to share.
